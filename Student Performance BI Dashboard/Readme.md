# Educational Performance & Resource Allocation Dashboard
## 🔍 Project Overview

This project analyzes student academic performance and support resources using a Kaggle Student Performance Dataset (2,392 records). The goal is to help education stakeholders understand how academic outcomes relate to study behavior and support systems and to identify where targeted interventions are required.

Since explicit institutional resource data was unavailable, educational supports such as tutoring, parental support, extracurricular activities, sports, music, and volunteering were treated as proxy resources for allocation analysis.

## 🎯 Objectives

Evaluate student performance using GPA, pass rate, study time, and absences

Analyze utilization of academic support resources

Identify high-risk student groups needing intervention

Enable data-driven decisions for educational management

## 🧠 Key Questions Answered

How does GPA vary by study time and absences?

Which demographics show lower academic outcomes?

Are support resources equitably distributed?

Which students are most at risk due to low support and poor performance?

## 🚩 Key Insights

Students with low study time and high absences consistently underperform

Tutoring and parental support significantly correlate with higher GPA

Certain demographic groups show lower resource participation

A clear segment of high-risk students lacks both academic support and engagement

## ✅ Outcome

The dashboard enables stakeholders to:

Prioritize tutoring allocation

Identify at-risk students early

Improve equity in educational support

Make data-backed academic policy decisions
